对于复习基础知识这块，我的经验是：

- 优先 408 ，其中 计网 = 操作系统 = 数据结构 >> 计算机组成原理
- 对于数学部分，重点是理解知识点，比如 介绍一下概率论中大数定律、线性代数的奇异值分解等重要考点
- 机器学习和深度学习的话，优先机器学习，深度学习重点了解重要的网络和基础，比如：介绍一下 KMeans 算法、 介绍一下 Transformer / BERT（如果你的项目或科研有涉及）、 深度学习中的 BN 层 等
- 一些重要的基础常识，比如：程序的堆区、栈区和数据区都是存放什么东西，用来干么的？

大体来说，考察 408、数学和 AI 这块都会是比较少的。如果老师一直问你这些知识的话，那应该好好反思一下是不是没有项目或科研经历。

因为老师本身也不喜欢问这些内容（除非是专门教这门课的），其次，通过项目和经历才能更加准确地了解一个学生的综合水平，问这些东西无法证明太多东西。

当然，如果你是报北航的话，我建议你应该好好去复习你本科期间所学过的所有相关专业课和基础课，因为他们是真的会啊。
