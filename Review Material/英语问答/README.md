# 关于英语面试

对于英语这块，大部分是要看学校的。以 SEU 为例子，是讲完 PPT 会有个英语提问，可能涉及的方面有 **项目（大多数）、基础课、自我介绍**等简单问题。

在这里我分享了我准备的一些基础简单问题（自我介绍、介绍家乡等），基本足够覆盖简单问题

而对于针对项目的问题，因人而异，要结合自己的项目，站在老师的角度去思考，他们会怎么问。大多数的提问都是：**项目中的挑战、你的贡献或主要工作、介绍一下项目中的某某模块**等。这个的话主要看个人，其实也是大同小异。

而如果是问基础课，我的评价是：毁灭吧。大部分人中文讲都磕磕绊绊，英语的话再加上专业名词..... 有这时间不如祈祷不会问到这个

至于怎么锻炼自己的口语水平，我当时是手机下载了个**豆包**，然后里面有个英语对话，每天或几天和她聊一会，锻炼语感。同时把问题多背背，也是一个不错的方法。
